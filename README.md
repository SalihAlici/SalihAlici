# Salih Alıcı

I work on embedded systems, real-time control and satellite ground station software. My projects cover sensor integration, motor control and communication protocols on microcontroller-based systems; telemetry and control interfaces on the desktop; and RTL design and simulation on the hardware side.

## Projects

| Project | Description | Technologies |
|---|---|---|
| [mercom1-fw](https://github.com/SalihAlici/mercom1-fw) | Firmware and control application for a three-axis pointing system that keeps an antenna locked on a target from a moving platform | C/C++, Teensy 4.1, STM32, Python |
| [MERGEN-KAT1-GCSS](https://github.com/SalihAlici/MERGEN-KAT1-GCSS) | Model satellite and CubeSat ground station: telemetry, charts, map, 3D model, camera recording; three versions for different missions | C#, WinForms |
| [MERGEN-KAT3-GCSS](https://github.com/SalihAlici/MERGEN-KAT3-GCSS) | Model satellite ground station with GPS-based antenna tracking | C#, WinForms |
| [Mergen-GCSS](https://github.com/mergenmodeluydu/Mergen-GCSS) | Model satellite ground station: Wi-Fi telemetry, charts, map, 3D model, camera stream and satellite commands | C#, WinForms, TCP |
| [riscv-ai-coprocessor](https://github.com/SalihAlici/riscv-ai-coprocessor) | FP4 SIMD AI accelerator attached to the PicoRV32 RISC-V core | Verilog, Verilator, C |

## Areas of expertise

- **Embedded software:** STM32, Teensy, Arduino / PlatformIO, timer interrupts, SPI / I2C / UART
- **Motors and sensors:** stepper motor control, closed-loop control with encoders, IMU-based orientation tracking, PI control
- **Communication:** LoRa (E22), serial protocol design, CRC
- **Desktop software:** C# / WinForms, Python / Tkinter
- **Hardware design:** Verilog, RISC-V, Verilator simulation
