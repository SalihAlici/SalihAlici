# Salih Alıcı

Gömülü sistemler, gerçek zamanlı kontrol ve uydu yer istasyonu yazılımları alanında çalışıyorum. Mikrodenetleyici tabanlı sistemlerde sensör entegrasyonu, motor kontrolü ve haberleşme protokolleri; masaüstü tarafında telemetri ve kontrol arayüzleri; donanım tasarımı tarafında ise RTL geliştirme ve simülasyon üzerine projeler yürütüyorum.

## Projeler

| Proje | Ne yapıyor | Teknoloji |
|---|---|---|
| [mercom1-fw](https://github.com/SalihAlici/mercom1-fw) | Hareket hâlindeki bir platformda anteni hedefe kilitli tutan üç eksenli yönlendirme düzeneğinin gömülü yazılımı ve kontrol arayüzü | C/C++, Teensy 4.1, STM32, Python |
| [MERGEN-KAT1-GCSS](https://github.com/SalihAlici/MERGEN-KAT1-GCSS) | Model uydu ve CubeSat yer istasyonu: telemetri, grafikler, harita, 3B model, kamera kaydı; farklı görevler için üç sürüm | C#, WinForms |
| [MERGEN-KAT3-GCSS](https://github.com/SalihAlici/MERGEN-KAT3-GCSS) | Model uydu yer istasyonu ve GPS tabanlı anten takip yazılımı | C#, WinForms |

## Uzmanlık alanları

- **Gömülü yazılım:** STM32, Teensy, Arduino / PlatformIO, zamanlayıcı kesmeleri, SPI / I2C / UART
- **Motor ve sensörler:** adım motoru sürme, enkoderle kapalı çevrim, IMU ile yönelim takibi, PI kontrol
- **Haberleşme:** LoRa (E22), seri protokol tasarımı, CRC
- **Masaüstü yazılım:** C# / WinForms, Python / Tkinter
- **Donanım tasarımı:** Verilog, RISC-V, Verilator simülasyonu
